## 🚀 Shipped Products

### Zerbook — Digital Ledger for Jewelers
> Flutter · ASP.NET Core 10 · PostgreSQL · SignalR · FCM · Twilio SMS

A production SaaS application for jewelry businesses to manage inventory, track gold in micrograms, and handle customer accounts. Features JWT auth, real-time notifications, SMS reminders, and is live on Google Play with paying customers.

---

### HırdavatPOS — Hardware Store Management
> Flutter · ASP.NET Core · PostgreSQL

E-commerce and order management platform for hardware store owners. Independently shipped with paying customers. Full product catalog, order tracking, and invoicing.

---

### Entegram — Swipe-Based Language Learning App *(Beta)*
> Flutter · ASP.NET Core · PostgreSQL

A swipe-based mobile app for Turkish/English learners — think flashcards meets modern UX. Users swipe through vocabulary and phrases with spaced repetition logic. Currently in beta testing. (EN + TR + gram)

---

### BidsForShips — Maritime Bidding Platform
> Django REST Framework · PostgreSQL · Multi-tenancy · RBAC

Multi-tenant platform used by **3,000+ companies** for maritime supply chain bidding. Role-based access control, real-time bidding engine, and complex business logic handling international freight workflows.
